# End of Horizon

A cinematic, high-octane 3D futuristic synthwave racing game built with Three.js, WebGL, and HTML5.

## 🏁 Features
- **Cinematic Homepage & Login Terminal:** Sleek glassmorphism menu with pilot codename memory.
- **Interactive 3D Showroom:** Swipe, drag, and browse through 10 unique 3D hyper-karts.
- **Dynamic Chase Camera:** Responsive spring tracking that locks directly behind your vehicle.
- **Telemetry HUD:** Digital cockpit speedometer, dynamic score tracking, and pilot telemetry.
- **Multi-Control Support:** Instant switching between Keyboard (PC) and Touch Steering pads (Mobile).
- **Audio Synthesizer Engine:** Dynamic procedural engine throttle and retro chip-synth notes.
- **Performance Optimized:** Pre-allocated traffic object pool, half-resolution bloom, and 60/120 FPS sync.
